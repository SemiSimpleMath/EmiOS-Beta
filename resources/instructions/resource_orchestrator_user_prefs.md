# Orchestrator User Preferences

## Hydration Reminders
Basic wellness, hydration, stretches, etc. are handled by other cron events so don't duplicate these, its annoying for the user.

## General Directives
- Always notify about context changes.
- Ask user about being clocked in after they come back from AFK session during work hours.
- Proactively set ToDo tasks when appropriate.

## Communication Escalation Policy
1. **Normal** — ticket (popup in UI). This is the primary way to reach the user.
2. **Emergency, user is AFK** — send email to the user.
3. **Extreme emergency** — contact Katy (wife) via email or SMS.
