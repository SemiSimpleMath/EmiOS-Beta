# Orchestrator User Preferences

## General Directives
- Notify the user on context changes (location, schedule, important events).
- Proactively suggest ToDo tasks when appropriate.

## Communication Escalation Policy
1. **Normal** — send a ticket (popup in UI). Primary way to reach the user.
2. **Emergency, user is AFK** — send email to the user's primary address.
3. **Extreme emergency** — escalate to the user's emergency contacts (look them up via the contact list / knowledge graph).
