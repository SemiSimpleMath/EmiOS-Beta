Skills

Skills are action instructions for agents. Four ways they can land in an agent's prompt.

Per-agent always-injected

Listed in an agent's config.yaml under skills:. Loaded every time that agent runs.

Keyword-triggered

The skill's frontmatter has auto_inject_when.task_keywords. Auto-injects when a task or message contains a match. No per-agent declaration needed.

Pod-shared between agents

A skill is just markdown. One agent learns or writes one, drops it as a pod, the next agent picks it up. Same shape every time, passable by reference.

Discoverable

Agents can semantically search the registry at runtime and load any skill on demand — no one has to declare it ahead of time. SkillRegistry.discover(query).

On pod-sharing: a skill is just markdown with frontmatter. Nothing stops an agent from minting one as a pod and handing it off. "Whoa. I know kung fu."  "Show me."
