Skills

Skills are action instructions for agents. Resources are data — different concept. Three ways skills get into an agent's prompt.

Per-agent always-injected

Listed in an agent's config.yaml under skills:. Loaded every time that agent runs. The user-editable ones live below as featured editors (Email, Dayflow).

Keyword-triggered

Skill's frontmatter has auto_inject_when.task_keywords. Auto-injects whenever the agent's task / incoming message contains one of the keywords. No per-agent declaration needed.

Shared across agents

Same skill referenced in multiple agents' skills: lists. Built once, reused.

Worth knowing: a skill is just markdown with frontmatter. Nothing stops a skill from being passed agent-to-agent as a pod attachment — one agent learns something, drops it as a skill pod, the next agent picks it up. "Whoa. I know kung fu."  "Show me."
