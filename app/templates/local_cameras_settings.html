How to add or edit

Local cameras are configured in configs/smart_home_tools.json under the local_cameras.devices array. Each entry needs alias, host, port, path, username, and password_env_var (the env var name that holds the actual RTSP password — never put the password in the JSON file). Set the env var in your shell profile, then restart Flask. The local_camera_snapshot tool can then pull frames into the analyzer pipeline.

For the kinds-driven dispatcher (which analyzer runs, where frames are stored, when a pod gets minted), see configs/cameras.json.
