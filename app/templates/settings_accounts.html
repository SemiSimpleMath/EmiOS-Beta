How to add an account

  1. Add an account entry to the env registry declaring platform, handle_env, and auth (include env_ref, secret_label, secret_hint, and optionally validator for the configure UI).
  2. For Google accounts: add an entry to configs/oauth_accounts.json and drop the OAuth client JSON at the client_credentials path.
  3. Set the matching *_HANDLE env var in .env and restart so the row appears with handle resolved.
  4. For non-Google: click Configure on the row, paste the platform-issued secret (app password / API token), and let {{ assistant_name }} mint the auth.* pod for you. No file editing or restart needed.
