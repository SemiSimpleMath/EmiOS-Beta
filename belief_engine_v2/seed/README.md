# Belief seed / backup

`beliefs_seed.db` — a **standalone, immutable snapshot** of the current belief store,
copied from the live `emi.db` on **2026-06-08** (read-only; the live DB was not touched).

## Why it exists
1. **Backup** — the current beliefs are preserved independently of `emi.db`.
2. **Seed + test set for `belief_engine_v2`** — the new engine seeds its observation log
   from this, and we test the resolver / dedup / decay against *real* data (including the
   real proliferation it has to collapse).

## Contents (verified src == dst at copy time)
- `user_beliefs` — **6,275** rows (826 active, 5,447 deprecated, 2 contested), 20 cols.
- `belief_evidence` — **32,306** rows, 13 cols.
- Exact schema + indexes preserved.

## Rules
- **Immutable.** Do not edit this file. It's a fixed snapshot. To refresh, re-copy from
  `emi.db` (the live source of truth stays `emi.db` until v2 cutover).
- Gitignored (`*.db`) — contains household PII, never commit.
- The new engine should treat this as **read-only input**, projecting into its own v2 tables.

## How it was made
Per-table schema + row copy via a read-only connection to `emi.db`
(`file:emi.db?mode=ro`). See the belief-engine v2 docs: `scratch/BELIEF-ENGINE-{OLD,NEW}.md`.
